I'm Ryan Christensen. This site is my working notebook for homelabs,
infrastructure, and the software that connects them.

I publish the details I want to be able to find again: implementation notes,
tradeoffs, failure modes, and the occasional clean solution. The aim is useful,
inspectable writing without a lot of ceremony.

## About the site

The site is intentionally static. [Astro](https://astro.build/) and
[AstroPaper](https://github.com/satnaing/astro-paper) turn Markdown and MDX into
HTML, [Pagefind](https://pagefind.app/) adds search without a server, and GitHub
Actions publishes each change.

The source is available on
[GitHub](https://github.com/d4rk22/ryanchristensen.net).
